# salesfoundationroleplay

Jack's First Appointment — an interactive role-play prototype for the **Sales Foundations** TSDR module (the reworked Do section).

- Learner plays the consultant through Jack's first appointment.
- Practises: read issue vs need, don't present too soon, choose the right question, connect a benefit to the real need.
- Single self-contained `index.html` (Jack's photo is embedded).
